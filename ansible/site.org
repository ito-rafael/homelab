This is the master orchestration file. It maps host groups from the inventory to specific task files within the =lbic= role.
#+begin_src yaml
---
#+end_src
** Proxmox Hypervisor
Runs against the physical host to configure bridges and networking.
#+begin_src yaml
- name: Configure Proxmox Hypervisor
  hosts: proxmox
  become: yes
  tasks:
    - name: core | proxmox | configure Proxmox network interfaces
      ansible.builtin.import_role:
        name: proxmox
        tasks_from: network.yml

    - name: core | proxmox | configure Proxmox APT repositories
      ansible.builtin.import_role:
        name: proxmox
        tasks_from: repositories.yml

    - name: core | proxmox | download LXC templates
      ansible.builtin.import_role:
        name: proxmox
        tasks_from: download_lxc_templates.yml

    - name: core | vyos | build VyOS image on Proxmox server
      ansible.builtin.import_role:
        name: vyos
        tasks_from: build_image.yml
#+end_src
** OpenTofu
Runs against the Proxmox server to provision the LXC containers and Virtual Machines.
#+begin_src yaml
- name: Provision LXC containers and VMs
  hosts: proxmox
  become: no
  tasks:
    - name: core | infrastructure | provision LXC containers and VMs
      ansible.builtin.import_role:
        name: proxmox
        tasks_from: provision.yml
#+end_src
** VyOS Router
Runs against the core router to configure VLANs and NAT via the network CLI.
#+begin_src yaml
- name: Configure VyOS Core Router
  hosts: vyos
  gather_facts: no
  tasks:
    - name: core | vyos | wait for VM boot and SSH available
      ansible.builtin.wait_for_connection:
        delay: 0      # start checking immediately
        sleep: 5      # check again every 5 s
        timeout: 300  # give up after 5 min

    - name: core | vyos | apply routing and NAT configuration
      ansible.builtin.import_role:
        name: vyos
        tasks_from: routing.yml
#+end_src
** Headscale VPN
Runs against the LXC container to install and configure the VPN controller.
#+begin_src yaml
- name: Configure Headscale VPN Controller
  hosts: headscale
  become: yes
  tasks:
    - name: core | headscale | install and configure Headscale VPN
      ansible.builtin.import_role:
        name: headscale
        tasks_from: headscale.yml

    - name: core | headscale | configure LXC TUN device access
      ansible.builtin.import_role:
        name: headscale
        tasks_from: lxc_tun.yml

    - name: core | headscale | install and configure Tailscale
      ansible.builtin.import_role:
        name: headscale
        tasks_from: tailscale.yml
#+end_src
