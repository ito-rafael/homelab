** Server
In order for the ='-J root@andira'= jumps to work, this host config must be in the =~/.ssh/config= file of the machine that will run the Ansible commands.
#+begin_src conf
Host andira
    HostName <SERVER-IP-ADDRESS>
    User root
#+end_src
