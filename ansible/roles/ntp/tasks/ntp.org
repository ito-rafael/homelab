* NTP
This configures Proxmox to pull time from the Brazilian NTP pool and serve it to the internal lab networks (10.10.0.0/16).
** Tasks
:PROPERTIES:
:header-args+: :tangle main.yml
:END:
#+begin_src yaml
---
#+end_src
*** Install chrony
#+begin_src yaml :padline no
- name: core | ntp | install chrony
  ansible.builtin.apt:
    name: chrony
    state: present
    update_cache: yes
#+end_src
*** Configure chrony server
#+begin_src yaml
- name: core | ntp | copy chrony config file
  ansible.builtin.template:
    src: chrony-server.conf.j2
    dest: /etc/chrony/chrony.conf
    owner: root
    group: root
    mode: '0644'
  notify: core | ntp | restart chrony systemd service
#+end_src
