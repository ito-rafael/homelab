** Automated
Source: https://pve.proxmox.com/wiki/Automated_Installation

The =proxmox-auto-install-assistant= tool provides the =prepare-iso= command to inject the automated installation into the ISO.

If you are in a Debian environment, you can install it with:
#+begin_src sh
apt install proxmox-auto-install-assistant
#+end_src

Since I'm not in Debian, the easier way to run this is with a container. I use =podman= for this, but if you use =docker= instead, simply replace the command in the next instructions.

This is the [[./Dockerfile][Dockerfile]] to create the image:
#+begin_src dockerfile
FROM debian:13-slim

ENV DEBIAN_FRONTEND=noninteractive

# install dependencies, add Proxmox keys/repos, and install the assistant
RUN apt-get update && \
    apt-get install -y wget ca-certificates && \
    wget https://enterprise.proxmox.com/debian/proxmox-release-trixie.gpg -O /etc/apt/trusted.gpg.d/proxmox-release-trixie.gpg && \
    echo "deb http://download.proxmox.com/debian/pve trixie pve-no-subscription" > /etc/apt/sources.list.d/pve-install-repo.list && \
    apt-get update && \
    apt-get install -y proxmox-auto-install-assistant && \
    apt-get clean && \
    rm -rf /var/lib/apt/lists/*

# map the host directory here
WORKDIR /work

# make the container act as the executable tool
ENTRYPOINT ["proxmox-auto-install-assistant"]
#+end_src

Build the image:
#+begin_src sh
podman build -t proxmox-assistant .
#+end_src

Run the container:
#+begin_src sh
podman run --rm -v $(pwd):/work proxmox-assistant prepare-iso /work/proxmox-ve_9.2-1.iso --fetch-from iso --answer-file /work/answer.toml
#+end_src
