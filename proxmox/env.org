* Proxmox
** User & Password
To generate the Proxmox hashed password, one can use the =mkpasswd= command.
#+begin_src sh
mkpasswd -m sha-512
#+end_src

#+begin_src conf
ADMIN_EMAIL="admin@domain.tld"
PROXMOX_PASSWORD_HASH='<YOUR-HASHED-PASSWD>'
#+end_src
** Network
#+begin_src conf
SERVER_FQDN="host.domain.tld"
SERVER_IP_CIDR="xxx.xxx.xxx/xx"
SERVER_GATEWAY="xxx.xxx.xxx.xxx"
SERVER_DNS="xxx.xxx.xxx.xxx"
SERVER_MAC="xx:xx:xx:xx:xx:xx"
#+end_src
** SSH Keys
#+begin_src conf
SSH_KEY_LAPTOP="ssh-ed25519 <YOUR-LAPTOP-PUBLIC-KEY> user@laptop"
SSH_KEY_DESKTOP="ssh-ed25519 <YOUR-DESKTOP-PUBLIC-KEY> user@desktop"
#+end_src
